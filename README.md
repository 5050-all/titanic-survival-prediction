# Titanic 生存预测项目

> 基于泰坦尼克号乘客数据集，使用 Python 完成数据分析与机器学习预测，是经典入门 AI 数据分析项目

## 项目简介
本项目使用泰坦尼克号乘客数据集，探索性别、舱位、年龄、票价等因素对生还结果的影响，最后构建逻辑回归模型预测乘客生存概率。

## 技术栈
Python、Pandas、Matplotlib、Scikit-learn

## 项目流程
1. **数据读取与查看**：加载 csv 数据集，查看基础信息、统计描述
2. **数据清洗**
   - Age（年龄）存在缺失值，使用均值填充
   - Embarked（登船港口）少量缺失，使用众数填充
   - Cabin（船舱号）缺失率极高，直接删除该列
3. **探索性数据分析 EDA**
   - 分析不同性别的生还率：女性生还率远高于男性
   - 分析不同舱位的生还率：舱位等级越高，生还概率越高
4. **数据可视化**：使用柱状图展示性别、舱位与生还率关系
5. **特征工程**：将性别文本(male/female)映射为 0/1 数值
6. **模型搭建**：逻辑回归模型，划分 80% 训练集、20% 测试集
7. **模型评估**：测试集准确率 81%

## 文件说明
- titanic.py：完整源代码
- train.csv：原始数据集

## 如何运行
1. 环境：Anaconda Python
2. 安装依赖包

```bash
pip install pandas matplotlib scikit-learn
```

3. 运行 titanic.py

## 项目结论
1. 性别是影响生还最重要的特征，女性生还概率显著更高
2. 舱位等级越高，乘客生存机会越大
3. 逻辑回归模型在该数据集上取得 81% 的预测准确率
